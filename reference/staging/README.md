# Staging

临时上传目录，用于把聊天里贴的参考图片提交进仓库，从而在会话环境里获得真实文件路径（供 `ppt-master` 的 Layout Reference 机制、`verify_template_fidelity.py` 几何校验等需要实际文件的流程使用）。

## 用途

聊天消息里直接贴的图片只进入模型的多模态输入，不会落地成本地文件；这个目录就是解决这个问题的中转点——图片提交进仓库后，下一次 `git pull` / 会话读取就能拿到真实路径。

## 使用方式

1. 把参考图片文件提交到这个目录下（文件名自定，建议保留可辨识的描述，例如 `batch1_01_europe_mbb.png`）。
2. 提交后告诉我文件名，我会读取内容确认，然后按具体任务（Layout Reference / 模板蒸馏等）处理。
3. 这里只是中转，不是长期归档位置——正式蒸馏/沉淀完成后，原始素材要么移到更合适的位置，要么按需清理，不在这里无限堆积。
